· Usuario no puede iniciar sesión
· Dashboard no carga / pantalla negra
· Loading infinito
· Admin sin contraseña
· Usuario normal entra admin
· Personalizado crea trial
· function() visible en pantalla
· Workout no abre
· Recetas no aparecen

· WhatsApp roto
· Error consola que bloquea flujo

· Pantalla saturada de info
· Sección que usuario no entiende

🔧 Protocolo de hotfix

✅ Permitido corregir
